oxanium-numeric-700.woff is a static weight-700 numeric/punctuation subset of
Oxanium[wght].ttf, generated using fontTools instancer + subset + WOFF output.
Glyphs: 0123456789:.,+-−–% and space/slash. 2,512 bytes; no remote font request.
The HUD uses this face; ordinary UI labels retain the system face.
