# fullsend — Full Send (rocket-bike sprint workout), 2D mockup
CONTRACT-REQUEST: none.
Design doc: the "Rocket bike sprint game: design brainstorm" Claude Doc. Dev game (`devGames`), so it shows in the picker with `?dev=1`.
## Sim (`sim/`)
- `tour.ts`: fixed tours (`quick` ~19 min, `classic` ~27 min). Each set = a set piece in a chosen biome with an effort length and a recovery. Titles, chaser per biome (volcano/jungle/desert = T. rex, snow = avalanche, sea = wave, moon/sky = boulder), default medal thresholds (FTP fractions).
- `physics.ts` (pure, tested): speed is linear in power/FTP (`kmhPerFtp`, 200) with a spool lag, so the same canyon works at any FTP. Leap gap = ballistic range at bronze speed; loop radius = v²/5g at bronze speed; `loopExit` says where a slow rider comes off; `smashCount`; `medalFor`.
- `sim.ts`: phases warmup → (approach → effort → payoff → recovery)×N → cooldown → done. Leap/Smash/Loop sit at the END of the sprint: their x is re-anchored each tick to `x + v × timeLeft`, so the sprint is exactly `effortS` long whatever your speed. Dive/Outrun span the sprint. Medals come from the built-up speed (leap/smash/loop) or the mean FTP fraction (dive/outrun). Misses are gags (geyser/rescue, foam pit, turtle tow, wall topples) and the tour always continues. Recovery power above `cruiseCap` adds no speed.
- Trainer: sim mode + virtual gears. Cruising grade = the warm-up terrain stretched `hillStretch`× (hills fade flat for set pieces). Overrides: run-up `runupGrade` 1 %, the loop climbs to `loopGrade` 5 % at the top and eases to the airtime grade on the way down (`loopGravity`/`loopSlowMo` stretch it to ~4–5 s), airborne `airGrade` −2 %, smash `smashGrade` 3 % (+2 % as hay piles on; the hay stuck to you keeps dragging for `smashHoldS` after), dive `diveGrade` 2 %.
- `track.ts` (pure, tested): seeded rollers (cosine humps) and kickers (smooth ramp, steep drop), ≤1 per 140 m, on the cruising road only (they scale with `hill`, so set pieces stay flat). Line Rider feel: on the road the bike takes off when `v²·h″ < −hopGravity` (fast riders leave crests slow riders roll over), flies ballistically, lands (a hard flat landing bounces), and slopes add/remove speed (`slopeGravity`). The trainer still follows only the smoothed big hills; a hop longer than `hopAirGradeS` eases it to `airGrade`. A trick (A) completed before landing scores style.
- Biome changes happen in the recovery before a set (`blendS` cross-dissolve). `hooks.shielded` is true during each sprint, so the `hook-responsive` script sprints them.
- Steering and landings: in a hop, paddles / D-pad left-right lean the bike back/forward (`leanRate`, plus a `leanDrift` toward the flight path). Landing grade = bike angle vs the slope (`perfectDeg`/`goodDeg`/`badDeg`); crest skips under 0.15 s are never graded, hops under `gradeAirS` can only be ok or bad. Bad = bounce + keep `badKeep` of speed + lose flow. Perfect/good add `flowPerfect`/`flowGood` to `flow` (≤ `flowMax`, decays `flowDecay`/s), which multiplies cruising target speed (never in a sprint, so medals stay effort-only). Hands-off riders never crash on bumps; `autolean` simOpt is a test pilot (~+17 % distance at Z2).
- Altitude (`Tier`: ground → sky → moon; falls land in the sea). Hops launch higher with flow (`launchGain`, capped `hopVyMax`). Cruising with flow above `liftFloor` fills `lift` over `liftFillS`; full = the next takeoff is a straight-up launch (`skyLaunch` / `moonLaunch`), the biome cross-fades on the way up and you arrive at the top of the arc. Sky: lift starts at `skyStartLift` and drains if flow drops; empty = you ride off the edge (`edgeX`), fall `plungeM`, the height is re-based (`warp`, renderer cuts its camera) and you splash into the sea. Moon: a fixed `moonS` stay with `moonGravity` floaty hops, then the same fall. Sea: `seaGravity`, +`seaGrade`, and you breach back to the road after `seaS` (or at any non-dive set's approach). Sets that start up high use the sky/moon biome. Bad landings cost `liftBad`.
- Moon exit: when moon time is up, the next takeoff throws you off (`moonExitVy`, or after 6 s anyway); falling uses full gravity, so re-entry burns (fireball) before the splashdown. Up high (sky/moon), `airItemAt` (track.ts) floats rings/stars at `airH`; rings add `ringFlow` + 4 % speed + `ringLift`, stars `starLift`. Jet: hold B/up in the air (or on the road) up high; fires only at ≥ `jetFtp` (`jetAccel`, `jetVyMax`, trainer `jetGrade`), else it sputters ('weak'). `autojet` simOpt is a test pilot (sets hooks.powerFtp for `target-follow`). Clean landings in a row (`chain`) multiply flow gains by `chainStep` per step (≤ 4). Ideas borrowed from Dolphin Olympics/Dolphin Up: clean entries boost speed and keep the chain, rings boost, the moon as a goal.
- Forks (Brian's pick): sprint order and lengths are fixed (the workout); every `TourSet` has an `alt` (kind + biome). The fork is open late in the warm-up (55–75 %) and early in each recovery (5–30 %); ◀ / ▶ picks (default = the plan), then the scenery blends to the chosen biome. Snapshot `fork`, `visited`; summary `route` (A/B per set), `biomesSeen`. `forks` simOpt ('main' | 'alt' | 'alternate') for tests. Up high, the sky/moon still override the set's biome.
- Setup screen (`menu`, `inMenu`, `receive` taps): tour (◀ ▶ / shifters), fewer flashes (no shake / flashes), start (A, or `menuAutoS`). Skipped when `tour` is given or `menu: false`. Save (`FullSendSave`): lastTour, reducedFlash, tipsSeen, best per tour, rides, moonVisits, maxAltM → `progressLine`. One-time tips (`tip`). Fork picks only count on the road (◀ ▶ lean in the air). Cadence shortens spool (`cadenceSpool`); seeded wind zones (`windAt`, `windGrade`, `windSpeed`). Chasers: shark (underwater), stone wheel (jungle). Sky/moon walls are cloud puffs / moon rocks.
- Sound (`render/sound.ts` glue, `render/soundCues.ts` pure + tested): rocket/roar/wind/jet/re-entry voices, one-shots by diffing snapshots, generative music per layer (ground, sprint, sky, moon, sea, menu). Goes quiet if frames stop (pause).
- Controls: none required. A = mid-air trick (style points). Shifters = virtual gears.
- Tunables: `fullsend.*` (speed, spool, cruise cap, approach, gravity, launch angle, slow-mo, smash count, chase gaps, air margin, hills, grades, and `<kind>Bronze/Silver/Gold`). `tourScale` shortens warm-up/recovery/cool-down for testing.
## Render (`render/`)
- Canvas 2D in the warm-up style (low-res buffer, crisp upscale, full-res text). **Borrows the warm-up's biome art read-only** (`LOOKS`, terrain, blend helpers) for the mockup; if Full Send graduates, move the shared biome art to a common module.
- World scale `PPM` 5.2 px/m both ways in a ~300-row buffer (`ROWS`; zoomed out so the rider is small and the road ahead readable; the bike reads ~5 m long, so 80+ mph scrolls ~500 CSS px/s). Loops are drawn round and the camera rises to fit them. `layout.ts` (tested) keeps the banner, sprint meter, speed, status and medal stamp above `insets.bottom`.
- `props.ts`: canyon (lava / glacier / river), flooded tunnel, loop ribbon with A-frame supports (vines / lacquer + lanterns / steel), stacked square hay bales that burst into straw (and straw stuck on the rider), other smash obstacles, chasers (an animated T. rex, avalanche, wave, boulder), and the rocket on a rack over the back wheel (stays to the rear axle and seat post, nose under the saddle; flame scales with power).
- `fx.ts`: cloud decks crossed on launches/falls, the sea surface, splashdown/breach splashes, re-entry fireball, rings and stars.
- Camera follows big flights (`alt`), hills sink as you climb. Lift meter (`liftMeter`) in the speed panel; SKY LAUNCH / MOON SHOT / OFF THE EDGE / BREACH banners (`flightCall`).
- Landing call-outs (PERFECT · FLOW +N% / CLEAN / BAD LANDING, `landingCall`) by the rider; FLOW +N% under the speed plate.
- Road signs (`signs.ts`, pure + tested): `planSigns` puts start gantries (3 red lights then green), distance boards (metres left, on a `SIGN` grid spaced so one is always in the ~100 m view), fork boards (pick highlighted) and NEXT billboards in the world; `countdown` feeds the big 3-2-1-GO and SPRINT/WALL distance, held monotone by `MonotoneCountdown`. HUD style: slanted plates, outlined italic type, caution-stripe tips, a highway-sign menu; no rounded boxes.
- Preview: `dev/fullsend.html?script=hook-responsive&tour=classic&sec=300` (`autolean=0` to fly hands-off; `manual=1` exposes `window.__fs.until(pred)` for captures).
## Tests
`npx vitest run src/games/fullsend` (scenarios via runHeadless, determinism, physics, tour lengths, layout).
- Type (`render/fonts.ts`, self-hosted OFL woff2 in `render/fonts/`): `fsFont(w, px, italic)`; italic = Barlow Condensed ExtraBold Italic (titles, numerals, call-outs), upright = Overpass 700/900 (highway-style boards, labels, tips).
- Overworld hand-off (`render/handoff.ts`, tested): the shell passes `simOpts.lobby` ({biome, v}); we start in that biome at that speed (`fromLobby`), draw at the lobby's pixel size/rider anchor and ease out to ours (`handoffMix`/`handoffRect`); `ending()` eases back in. `hooks.lobbyBiome` tells the shell which biome to resume the overworld in. Time of day follows the clock like the overworld (`daylight`, `?hour=`).
